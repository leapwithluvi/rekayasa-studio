## 1. PRINSIP BISNIS & SUDUT PANDANG KLIEN
- **Klien Membeli Hasil, Bukan Kode**: Klien tidak membeli framework atau baris kode. Mereka membeli kredibilitas, kemudahan ditemukan di Google, dan saluran pemesanan langsung ke WhatsApp.
- **Kepercayaan Mengalahkan Harga Murah**: Klien memilih freelancer/studio yang tertata rapi, responsif, transparan, dan dapat diandalkan.
- **DP 50% & Batasan Tertulis adalah Perlindungan**: Membatasi revisi dan mewajibkan DP adalah bentuk profesionalisme, bukan rasa tidak percaya.
- **Website adalah Pelengkap Media Sosial**: Website bukan pengganti Instagram/TikTok, melainkan hub resmi tempat seluruh produk, legalitas, alamat Google Maps, dan tombol WhatsApp tertata rapi di bio.

## 4. KETENTUAN UMUM SEMUA PAKET

1. **Domain**:
   - Bonus 1 domain `.my.id` gratis untuk tahun pertama atas nama klien. Perpanjangan tahun kedua dibayar klien.
   - Klien ingin `.com`, `.id`, atau `.co.id`: Klien membayar biaya domainnya, Altareka bantu proses pendaftarannya.
   - Klien sudah punya domain: Dihubungkan tanpa biaya tambahan, tanpa potongan harga paket.
2. **Hosting & SSL**:
   - Paket tanpa panel admin: Hosting statis gratis (Cloudflare Pages / Netlify / Vercel) + SSL selamanya sudah termasuk.
   - Paket dengan panel admin: Butuh hosting yang mendukung CMS (PHP/Node/Database). Klien beli sendiri (dibantu pasang maks 2 jam) atau sewa lewat Altareka.
3. **Materi Konten**:
   - Foto, teks profil, logo, dan data produk disiapkan oleh klien. Altareka bertugas menata arsitektur dan tata letak secara profesional, bukan membuat copywriting dari nol.
4. **Pembayaran & Termin**:
   - DP 50% di awal sebelum jadwal terkunci.
   - Pelunasan sebelum situs dipublikasikan ke domain utama atau sebelum penyerahan source code.
   - Khusus PT Premium: dapat menggunakan 3 termin (50% DP, 30% persetujuan desain, 20% pelunasan sebelum serah terima).
5. **Garansi Bug**:
   - Menjamin perbaikan kesalahan teknis (bug) pada versi v1.0 yang diserahkan selama 7–30 hari (sesuai paket).
   - Garansi gugur jika kode/sistem diubah oleh pihak ketiga atau terjadi kelalaian dari server hosting klien.

## 6. ATURAN DOMAIN, HOSTING, CMS & SOURCE CODE

### A. Perlindungan Hak Cipta & Source Code
- **Model Lisensi Hak Guna**: Setelah pelunasan, klien mendapatkan hak guna penuh atas website perusahaannya. Template dasar, arsitektur pondasi, dan komponen milik Altareka tetap menjadi milik pengembang dan boleh dipakai ulang untuk proyek lain.
- **Larangan Jual Ulang**: Klien tidak diperbolehkan menjual kembali kode atau mendistribusikannya sebagai template komersial ke pihak lain.
- **Portofolio Altareka**: Altareka berhak menampilkan tangkapan layar hasil website di portofolio resmi tanpa membocorkan data rahasia klien.

### B. Aturan Emas Serah Terima Source Code (Jika Klien Memiliki Tim IT Sendiri)
1. Persyaratan lingkungan server (PHP/Node/Database) dituliskan di awal pada kontrak & file `README.md`.
2. Uji terima (*User Acceptance Test*) dilakukan di server pratinjau Altareka.
3. Pelunasan wajib 100% sebelum source code / repositori diserahkan.
4. Semua password rahasia, token API pribadi, dan kunci staging dibersihkan dari repo sebelum diserahkan.
5. Garansi hanya berlaku untuk versi rilis awal `v1.0`.

## 7. SOP 10 TAHAP PENGERJAAN PROYEK

1. **Kontak Awal**: Identifikasi kebutuhan dan perkenalkan contoh karya nyata (PT. Bumi Kutai Perkasa).
2. **Diskusi Kebutuhan (Brief Form)**: Menanyakan tujuan web, target audiens, jumlah halaman, dan materi.
3. **Penawaran & Estimasi**: Mengirim Surat Penawaran 1 Halaman (PDF) dengan opsi paket yang jelas.
4. **Kesepakatan & DP 50%**: Mengunci jadwal kerja setelah DP masuk ke rekening resmi.
5. **Pengumpulan Materi**: Menerima logo, teks, foto produk, dan kontak WA dari klien.
6. **Desain / Prototipe**: Merancang tampilan responsif halaman utama untuk mendapatkan persetujuan arah desain.
7. **Pengembangan & Uji Coba**: Membangun website di server staging/pratinjau.
8. **Sesi Revisi**: Klien memberikan 1 daftar revisi terpadu sekaligus (sesuai kuota paket).
9. **Pelunasan**: Klien mengonfirmasi hasil akhir dan melunasi sisa pembayaran sebelum go-live.
10. **Go-Live & Serah Terima (BAST)**: Menghubungkan domain, mengaktifkan SSL, menyerahkan panduan/akses, penandatanganan BAST, dan meminta testimoni.

## 8. SISTEM DOKUMEN & LEGALITAS (3 TINGKAT)

- **Tingkat 1 (UMKM Kecil < Rp 2 Juta)**: Ringkasan kesepakatan tertulis di WhatsApp (klien membalas "SETUJU") + Invoice PDF sederhana + konfirmasi serah terima lewat chat.
- **Tingkat 2 (UMKM Menengah / PT Kecil Rp 2 - 5 Juta)**: Surat Penawaran 1 Halaman PDF resmi + Invoice DP & Pelunasan + Berita Acara Serah Terima (BAST) singkat 1 halaman.
- **Tingkat 3 (PT / Proyek Korporat > Rp 5 Juta atau Serah Terima Source Code)**: Kontrak Perjanjian Kerjasama (2–3 halaman) bertanda tangan + E-meterai Rp 10.000 + BAST formal + Kuitansi resmi.

## 9. PENANGANAN MASALAH & TEMPLATE KOMUNIKASI

- **Menolak Permintaan Tambahan Fitur (*Scope Creep*)**:
  > *"Terima kasih masukannya, Pak/Bu. Fitur [X] belum masuk dalam cakupan paket yang kita sepakati. Saya bisa menambahkannya sebagai fitur tambahan dengan estimasi biaya Rp [X] dan pengerjaan [X] hari. Kalau Bapak/Ibu berkenan, saya siapkan ringkasannya untuk disetujui."*
- **Mengingatkan Pelunasan Sebelum Go-Live**:
  > *"Halo Pak/Bu [Nama], website sudah siap 100% di server pratinjau. Sesuai kesepakatan, website akan langsung kami hubungkan ke domain utama setelah pelunasan invoice [nomor] kami terima. Mohon konfirmasi bukti transfernya ya Pak/Bu."*
- **Menghentikan Revisi Berulang yang Melebihi Batas**:
  > *"Halo Kak [Nama], kuota revisi gratis untuk paket ini sudah selesai kita gunakan dengan baik. Untuk penyesuaian baru di luar daftar sebelumnya, berlaku biaya revisi tambahan Rp [X] per sesi. Apakah ingin kita jadwalkan?"*

## 10. RENCANA RUTIN PENDAPATAN BERULANG (RECURRING INCOME)
- Tawarkan paket pemeliharaan (maintenance) setelah website berjalan 2–4 minggu.
- Pantau masa perpanjangan domain & hosting klien setiap tahun.
- Bantu update produk/promo musiman secara berkala dengan sistem retainer ringan.
